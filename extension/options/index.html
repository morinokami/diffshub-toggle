DiffsHub Toggle

Press your configured keyboard shortcut on a GitHub or DiffsHub page to switch to the matching page. Clicking the toolbar icon does the same thing.

The default shortcut is Alt+Shift+D (Option+Shift+D on macOS).

Settings

Notes

  • DiffsHub currently supports public GitHub diffs.
  • On other sites, the shortcut does nothing.
  • This extension is unofficial and is not affiliated with DiffsHub or GitHub.

Privacy

This extension does not collect or transmit any user data. Your settings are stored only in your browser (and synced between your devices by Chrome if you enable browser sync). It only changes the hostname of the active tab between github.com and diffshub.com when explicitly invoked by you.
